# Windows OpenCV provider notices

`COPYRIGHT.txt` is an exact copy of the copyright file supplied with the
OpenCV 4.14.0 x64-windows package used by the private Windows application
validation. It includes the provider's collected upstream license texts.
The original bytes and line endings are retained; `PROVENANCE.json` records
their identity and the observed installed package features.

The vcpkg checkout revision records the checkout as observed during collection.
It does not independently prove which revision originally built the installed
package. Its installed SPDX metadata reports `NOASSERTION` license fields;
those fields are not a substitute for the supplied license texts. No contrib
feature was present in the observed installed OpenCV package stanzas.

This is one component of the Windows dependency notice packet. It does not
establish completeness for OpenCL, zlib, Qt, FFmpeg and codecs, MDK, OpenColorIO,
Microsoft runtimes or other packaged components, or satisfy corresponding-source
obligations by itself. Include and review it with the final native packet before
distribution. No public application release is approved by this notice retention.
